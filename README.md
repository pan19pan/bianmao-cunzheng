# 山海银信 · 用AI让边境口头交易有凭可依

中越边贸口头交易 AI 存证与调解辅助系统——单文件网页应用，零安装、离线可用。

**在线演示**：<https://pan19pan.github.io/bianmao-cunzheng/>

> 推荐用 Chrome / Edge 打开。系统不联网、不上传任何数据，所有数据仅保存在本机浏览器中。

---

## 项目背景

中越边贸大量交易依赖口头约定与微信随口沟通，一旦违约，边民往往"说得出、拿不出"。本系统把散落在聊天记录、转账备注、单据照片里的关键承诺，**就地固定为可校验、可追溯、可出示的数字证据**，并为调解员提供一键生成案情分析报告的能力。

## 系统结构（四层递进）

| 层级 | 内容 |
|------|------|
| **第 1 层 · 引导** | 4 页滑动新手教程（支持左右滑动 / 键盘方向键 / 圆点跳页） |
| **第 2 层 · 入口** | 虚拟登录，选择「边民端」或「调解员端」两种身份 |
| **第 3 层 · 工作台** | 边民：三步存证向导；调解员：案件总览 / 存证管理 / AI 报告 |
| **第 4 层 · 深入层** | 我的存证、十三要素体检、AI 理解层、AI 内核、关键词库、合规与架构 |

顶栏四层面包屑可随时跳层，「← 返回」按操作历史逐层回退。

## 核心功能演示

### 1 · 三种材料录入（边民端）

- **手动输入**：口述补记
- **微信聊天粘贴**：整段聊天原文粘贴，保留时间与说话人
- **单据拍照上传**：原件单独计算 SHA-256 指纹，不转写、不裁剪

### 2 · AI 全程可见（DeepSeek）

| 环节 | AI 动作 | 弹窗展示 |
|------|---------|----------|
| 上传图片 | AI 脱敏 | 「AI 脱敏中」：指纹 → OCR → 姓名/手机/账号/金额打码 → 脱敏摘要 |
| 内容核验 | AI 要素抽取 | 对照 13 类要素 + 95 条中越双语关键词，逐句高亮 |
| 缺失检测 | AI 补存建议 | 缺哪项给哪项，附可直接发微信的补存话术 |
| 报告生成 | AI 归纳 | 校验指纹 → 脱敏 → DeepSeek 归纳 → 规则复核 → 排版 |

> 演示版在本地以等价规则引擎模拟 DeepSeek 调用过程，脱敏为真实实现；正式版接入 deepseek-chat API，仅将**脱敏后的结构化事实**送模，原文不出本机。

### 3 · 十三要素体检

按边境贸易交易要素 13 个维度逐项检查覆盖情况，缺什么、补什么，一眼看清；每项缺失附法学组预设的补存话术。

### 4 · 一键存证 · 数字指纹

内容 + 时间戳 → **SHA-256** 指纹（浏览器原生 Web Crypto，毫秒级）。指纹即"证据身份证"：事后任何一字改动，校验立即失败（调解员端内置「篡改演示」按钮可现场体验）。

### 5 · AI 案情分析报告（调解员端）

四部分 + 两组定向内容：

1. **可确认事实**——逐条附指纹，可回溯到原始存证
2. **缺失要素与争议点**
3. **十三维度覆盖分析**
4. **调解路径提示**
5. **调解员参考**（仅调解员可见）：沟通切入 / 方案试探 / 引导底线 / 安抚情绪 / 找共同点，五块可直接说出口的话术
6. **当事人提示卡**（仅边民端可见）：证据风险 / 应对提示 / 底线提示（能证明什么、不能证明什么）

支持打印存 PDF、下载独立 HTML、复制全文；可整份以越南语生成。

### 6 · 全系统越南语

右上角 **Tiếng Việt** 一键切换，从引导页到案情报告全量越南语（13 要素话术、12 条风险规则、95 条关键词、三案例对话、报告模板均含越南语版本）。

## 合规设计

- **数据不出本机**：无服务器、无账号体系，localStorage 本地持久化
- **最小化送模**：仅脱敏后的结构化事实进入大模型，原文不离开设备
- **留痕可审计**：每次 AI 调用记录时间 / 用途 / 模型 / 字符数 / 脱敏处数
- **分层信息隔离**：调解员参考与当事人提示卡按角色定向展示

## 本地运行

无需安装任何依赖，双击 `index.html` 即可在浏览器中打开运行。

## 技术说明

- 纯前端单文件 HTML（约 320 KB），零外部依赖、可离线运行
- SHA-256：Web Crypto API + 纯 JS 兜底实现（经 Node 对照 13 组测试用例校验）
- 大模型：DeepSeek-V3（deepseek-chat），演示版以本地等价规则引擎模拟
- 数据持久化：浏览器 localStorage，可一键重置
